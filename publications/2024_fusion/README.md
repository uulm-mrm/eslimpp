# Conflict Handling in Time-Dependent Subjective Networks 

The scripts in the `paper` directory will create some of the images used in the paper with the title above.
Additionally, the `presentation` directory contains some contains scripts to generate images used in the presentation of the paper at the conference (they might not be up to date with the newest library interface, sorry...).\
Evaluations can be run as described in [here](../README.md).

## Experiment description

A barycentric triangle showing a binomial opinion is generated by `barycentric_triangle.py`.
It includes axis labels and the projection properties of an opinion.\
The in depth investigation on trust revision operators is available in `trust_revision_josang_ours.py` and `trust_revision_sweep.py`.
Using barycentric triangles, the impact of trust revision is demonstrated.\
Next, the evaluation on time series is available in `time_series_weather_forecast.py`.
Here, the progression of the projected probability and the errors are plotted in two different figures.



TLDR:
1) barycentric triangle illustration:
```bash
    barycentric_triangle.py
```
2) single step trust revision:
```bash
    trust_revision_josang_ours.py
    trust_revision_sweep.py
```
3) time series evaluation using trust revision:
```bash
    time_series_weather_forecast.py
```
